New `scroll-fade` utility: add it to anything that scrolls and its edges fade where there is more to scroll. It's a mask, so it works on any background, and each fade grows with the first 2.5rem of scroll instead of popping in (set `--scroll-fade-size` to change that length, and `--scroll-fade-inset` to start it below something laid over the edge, as Select does under its scroll arrows). A fade never takes more than a quarter of the box, so a short list keeps a row clear between its two fades. It follows the element's own scroll in Chrome, Edge and Safari 26+. In `ScrollArea` it also works in Firefox, which doesn't have scroll-driven animations yet; elsewhere Firefox simply shows no fade. `ScrollArea`'s fade now uses it, so it grows smoothly instead of switching on. Whatever is scrolled into view, such as an item reached with the arrow keys, stops clear of whatever is faded at that moment.

Every dropdown now scrolls the same way: Menu (with its submenus and Menubar's menus), ContextMenu, Select, Combobox and Autocomplete. The popup keeps its background, edge and shadow while a list inside it scrolls, and that list fades at the top and bottom instead of showing a scrollbar. Where the browser can't fade it yet (Firefox, for now), the list shows its native scrollbar instead, so a Combobox in Firefox now has one too. A long option no longer scrolls the list sideways, and scrolling to the end of a list no longer carries on into the page behind. Select now scrolls its list rather than its popup, as in Base UI's own example, and Autocomplete scrolls its `AutocompleteList` the way Combobox does.

Menu and ContextMenu have a new element inside the popup for this, `data-slot="menu-list"` and `data-slot="context-menu-list"`, which holds the items and the padding. Padding you pass to `MenuContent` or `ContextMenuContent` through `className` now sits around the list rather than around the items, and a selector aimed at the popup's direct children (`*:data-[slot=menu-item]:…`) no longer reaches them. Style the list from the popup instead, for example `className="*:data-[slot=menu-list]:p-0"`. PageUp and PageDown still scroll a menu opened with the pointer.
