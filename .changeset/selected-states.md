Every chosen state now uses `selected`: the current tab, the Sidebar's current page, a pressed Toggle, a checked Checkbox, Radio or Switch, and a selected Table row. It is still `primary` by default, so nothing looks different; set `--selected` to restyle all of them at once. Chosen items keep white text, so pick a colour it reads on, such as a darker shade of your brand colour. Brand fills (the default Button, Badge, the Avatar badge, Progress and Slider's range) stay `primary`.
